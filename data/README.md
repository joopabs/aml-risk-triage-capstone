# Data

> Educational decision-support prototype trained on synthetic PaySim data. Outputs are risk scores and review priorities that help human investigators decide what to review first. This system makes no fraud or AML determination and performs no automatic blocking, account closure, customer risk rating, or regulatory reporting. Results on synthetic data do not establish real-world detection effectiveness, fairness, or regulatory suitability.

## Synthetic notice

PaySim is synthetic mobile-money transaction data generated by a simulator. It is **not** real
SME, corporate, or Philippine banking data, and nothing derived from it establishes real-world
detection effectiveness, fairness, or regulatory suitability.

## Checksum

`scripts/fetch_data.sh` verifies the downloaded file against the SHA-256 recorded in
`configs/data_source.yaml` and refuses to proceed on mismatch.

## Fetch

```bash
make data
```

With `KAGGLE_USERNAME` and `KAGGLE_KEY` in the environment (or an untracked `.env`), the script
uses the Kaggle API. Otherwise it prints manual download instructions and waits for the file in
`data/raw/`. Raw and processed files are gitignored and never committed.

## Layout

- `raw/` — the downloaded CSV (local only)
- `processed/` — parquet splits and feature matrices regenerated by `make pipeline` (local only)
